git diff — показывает разницу между двумя состояниями (например, между коммитами).
git show — показывает содержимое одного коммита (метаданные + изменения).
git log — показывает историю коммитов (можно фильтровать).
-S"def" ищет коммиты, где изменилась строка с текстом def (поиск по содержимому).
blame показывает, кто и когда менял каждую строку файла.

git restore без --source берёт состояние из последнего коммита (HEAD).
С --source=HEAD~2 восстанавливает состояние из указанного коммита.
Если бы были свои несохранённые правки, restore их перезаписал бы (они пропали бы).
