- `git diff` показывает изменения между рабочей директорией и индексом или между коммитами.
- `git show` показывает подробную информацию о конкретном коммите и внесенные в нем изменения.
- `git log` показывает список коммитов (историю).
- `git log -S"def"` ищет коммиты, в которых менялось количество вхождений строки "def".
- `git blame` показывает, какой автор и в каком коммите последний раз менял каждую строку файла.


- `git restore` возвращает файл к последнему коммиту, отменяя незакоммиченные изменения.
- `git restore --source=HEAD~2` берет версию файла из конкретного старого коммита.
- Если бы я не вернул файл обратно, мои несохраненные правки были бы безвозвратно удалены.

- `git revert` создает новый коммит, который отменяет изменения ошибочного коммита. История не переписывается.
- `git reset --hard` удаляет коммиты из истории (переписывает её).
- `revert` безопаснее для опубликованной истории, так как не ломает репозиторий у других разработчиков (не требует push --force).
