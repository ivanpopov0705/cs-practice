Рабочая папка - обычная папка на компьютере, где лежат файлы. Можно открыть их в редакторе, редактировать, добавлять новые или удалять ненужные.
Индекc - куда ты добавляешь файлы командой git add, чтобы подготовить к коммиту.
Коммит - это зафиксированная точка в истории проекта. Снимок проекта в определённый момент времени, который сохраняет все внесённые изменения.

Git - это локальная система контроля версий: она работает у меня на компьютере.
GitHub - это сервис, где хранятся репозитории, можно делать пулл‑реквесты, обсуждать изменения и т. д.
То есть Git — это инструмент, а GitHub — место, где можно хранить и совместно работать с репозиториями.

git status - показывает состояние: какие файлы изменены, какие добавлены, на какой ветке я нахожусь.
git diff - показывает разницу между рабочей папкой и индексом/коммитом.
git diff --staged - показывает, что уже добавлено в индекс и будет в следующем коммите.


Ветка - это указатель на конкретный коммит.
При новом коммите ветка автоматически сдвигается вперёд.
Слияние (merge) объединяет изменения из одной ветки в другую.
Флаг --no-ff создаёт отдельный коммит слияния, чтобы в истории было видно, что была отдельная ветка.
